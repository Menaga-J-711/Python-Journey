## 🗓️ Daily Learning Approach

My approach is simple:

**Learn → Practice → Solve → Document → Commit → Improve**

For each learning day, I aim to:

1. 📖 Learn the concept
2. ✍️ Write notes
3. 💻 Practice with small programs
4. 🧠 Solve problems
5. 🐛 Understand and fix mistakes
6. 📌 Save the work in this repository
7. 🔀 Commit the progress using Git

This repository therefore acts as both a **learning journal and coding portfolio**.
